# API

NeuroFlow exposes a REST API under `/api/v1/`. The **OpenAPI** schema is generated by FastAPI.

## Base URL

Local development: `http://127.0.0.1:8000`

## Endpoints

### Health

`GET /api/v1/health`

```json
{
  "status": "ok",
  "version": "0.1.0"
}
```

### Datasets

`GET /api/v1/datasets`

Returns summaries for the dataset at `NEUROFLOW_BIDS_ROOT`.

```json
[
  {
    "name": "sample",
    "path": "/path/to/data/sample",
    "subjects": ["01"],
    "description": "NeuroFlow Sample"
  }
]
```

### Errors

```json
{
  "detail": "Human-readable message",
  "code": "bids_root_missing",
  "field": null
}
```
