Host tools

NeuroFlow detects neuroimaging packages on the machine; it does not install them.

Install FreeSurfer, FSL, and other tools with their official procedures, then ensure binaries are on PATH or set overrides in .env.

Typical probes / overrides

Package Probe / override
FreeSurfer recon-all on PATH, or NEUROFLOW_RECON_ALL_BIN / NEUROFLOW_FREESURFER_HOME
FSL FSLDIR / NEUROFLOW_FSLDIR
Spinal Cord Toolbox (SCT) sct_version on PATH, or SCT_DIR / NEUROFLOW_SCT_DIR
ANTs ANTSPATH / NEUROFLOW_ANTSPATH
3D Slicer SLICER_HOME / NEUROFLOW_SLICER_HOME
ITK (CSIM) Paths in config/itk-binaries.json

Scan and rescan

On API startup, NeuroFlow scans the host for registered packages and caches the result. After sourcing a tool environment (for example FreeSurfer), re-scan without restarting: 

curl -X POST http://127.0.0.1:8000/api/v1/host/rescan

From a terminal in the repo you can also run poetry run neuroflow scan or ./scripts/check-host-tools.sh.

Reading module status

  • Ready — binary found; you can open and run the module.
  • Install on host — install or fix PATH / .env, then rescan.
