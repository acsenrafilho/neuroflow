FAQ

Common questions. Full answers: FAQ on Read the Docs.

Does NeuroFlow install FreeSurfer, FSL, or SCT?

No. Install those packages yourself. The portal only detects them. See Host tools.

Why does a module say Install on host?

The probe binary was not found. Fix PATH or .env, then rescan or restart the API.

Why is my job queued?

Host RAM or CPU is above the configured limits, or the queue is full. See Jobs & logs.

Is there a login? Can I put this on the internet?

There is no authentication. Do not expose an unauthenticated instance to the public internet. See Data & privacy.

Does it run on Windows or macOS?

Windows: browser on Windows, compute in Linux on WSL2 Ubuntu. NeuroFlow never auto-installs WSL. The Windows .exe is a launcher only — it does not run FreeSurfer, FSL, or SCT on native Windows. See Windows + WSL.

macOS: a packaged portal zip is available (experimental). Host tools must still be native installs where vendors support them.

Does NeuroFlow install WSL?

No. If WSL or Ubuntu is missing, NeuroFlow explains and links to Microsoft's install guide. Admin rights and a possible reboot are part of Microsoft's installer.

Does it chain pipelines or use Docker?

No automatic pipelines and no Docker requirement. Each module is one job. Tools stay on the host OS.

Where are ANTs, Slicer, and ITK?

They are not listed in the portal UI yet. Use FreeSurfer, FSL, and SCT while those packages remain Coming soon.
