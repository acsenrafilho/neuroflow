Windows and WSL

On Windows, you use NeuroFlow in Chrome while processing runs in Linux on WSL2 Ubuntu. Full guide: Windows and WSL on Read the Docs.

info One-sentence story

Click NeuroFlow on Windows, use the site in Chrome, and processing happens in Linux on WSL — provided WSL and the neuroimaging tools are already installed. NeuroFlow guides you to official docs; it does not install WSL or vendor CLIs for you.

Requirements

  • Windows 11 + WSL2 is the primary target. Windows 10 + WSL2 is supported with possible localhost caveats.
  • Distro name: Ubuntu (do not substitute Debian or docker-desktop).
  • x86_64 for v1. ARM Windows is out of scope.
  • Host tools (FreeSurfer, FSL, SCT) installed inside Ubuntu, not on the native Windows PATH.

Install WSL yourself

NeuroFlow never auto-installs WSL, never runs wsl --install, never reboots your PC, and never enables Windows features on your behalf.

If WSL or Ubuntu is missing, follow Microsoft's official WSL install guide. Admin rights and a possible reboot are part of Microsoft's installer. On first Ubuntu launch, create a Linux username and password (not your Windows account).

WSL does not reserve a fixed partition. The Ubuntu virtual disk grows with use. FreeSurfer, FSL, and SCT will consume many gigabytes inside Linux once installed.

Where data lives

Jobs and datasets live under ~/.neuroflow/ in the Ubuntu home — not under C:\Users\... or on /mnt/c as the primary store.

How to run today

Current Windows release zip

Today's Windows zip still ships a native Win32 portal — that is not the supported neuroimaging path.

Supported today: install WSL2 + Ubuntu, download the Linux release zip, run neuroflow inside an Ubuntu terminal, then open Chrome on Windows at http://127.0.0.1:8000/.

How the Windows zip will work

A future release will ship NeuroFlow.exe (launcher) plus linux-payload/. Double-click will start the Linux portal in Ubuntu and open your browser on Windows. If WSL is missing, the launcher will show a guide and link to Microsoft — still with no auto-install.

Unsigned builds may trigger SmartScreen — choose More info → Run anyway when you trust the release source.

Host tools in Ubuntu

NeuroFlow does not download FreeSurfer, FSL, or SCT. Install them inside Ubuntu, then rescan: 

curl -X POST http://127.0.0.1:8000/api/v1/host/rescan

If Home shows Install on host, the probe did not find the CLI in Ubuntu — not a Windows PATH issue. See Host tools.

Troubleshooting

  • Ubuntu not initialized — open Ubuntu from Start and complete Linux user setup.
  • Port 8000 busy — stop the other process or wait until it finishes. NeuroFlow will not kill that process.
  • linux-payload missing — place the Linux onedir next to NeuroFlow.exe, or set NEUROFLOW_LINUX_PAYLOAD.
  • Second double-click — if the portal is already up, NeuroFlow only opens the browser again.
  • Browser cannot reach portal on Windows 10 — WSL2 localhost forwarding may differ; try from inside Ubuntu first.
  • ARM Windows — not supported in v1.
