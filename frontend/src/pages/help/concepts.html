Concepts

How NeuroFlow fits between your browser and the neuroimaging software installed on the host.

Portal vs host tools

NeuroFlow is the portal: a FastAPI backend plus HTML pages. FreeSurfer, FSL, and other packages remain separate installs on the same machine. The portal detects them, builds allowlisted commands from form fields, and streams logs—it never ships those CLIs inside this repository.

One module per page

Each processing module is a dedicated page (upload, parameters, CLI preview, run, logs). There is no cross-tool pipeline composer or shared orchestration DAG. If a workflow needs several stages (for example TOPUP then EDDY), you run each as its own job.

Jobs on disk

When you execute a module, the API creates a job folder under data/jobs/ with inputs, metadata, and a merged run log. Researcher-oriented outputs also land under a BIDS-inspired tree in data/datasets/ when workspace and subject fields are set. See Workspaces and Jobs & logs.

Local / trusted network

The MVP has no authentication. Use NeuroFlow on localhost or a trusted lab network only. Details are in Data & privacy.
