Modules

How to use packages inside NeuroFlow. For CLI flag reference, always open the Official documentation link on the module page. The full module catalog is also on Read the Docs.

FreeSurfer

Cortical reconstruction and volumetric segmentation (for example recon-all). Ensure FreeSurfer is installed and discoverable (recon-all on PATH, or overrides in .env).

  • Package overview: /packages/freesurfer.html
  • Module page: /tools/freesurfer.html
  • Vendor site: surfer.nmr.mgh.harvard.edu

FSL

Structural, diffusion, and registration tools. NeuroFlow exposes one module page per FSL program (BET, FLIRT, TOPUP, EDDY, and others). Run each stage as a separate job; the portal does not chain pipelines automatically.

Many advanced modules show a Before you run panel with prerequisite steps (for example TOPUP before EDDY). Complete those first using other modules or your own prepared inputs.
  • Package overview: /packages/fsl.html
  • Example module: /tools/fsl.html?module=fsl-bet
  • Vendor docs: FSL documentation

Spinal Cord Toolbox (SCT)

Spinal cord MRI segmentation, vertebral labeling, PAM50 template registration, and morphometrics. NeuroFlow exposes one module page per Phase 1 CLI (sct_deepseg, sct_propseg, and others). Run each stage as a separate job; the portal does not chain pipelines automatically.

Ensure SCT is installed with the official installer, then verify sct_version is on PATH or set SCT_DIR / NEUROFLOW_SCT_DIR.
  • Package overview: /packages/sct.html
  • Example module: /tools/sct.html?module=sct-deepseg
  • Vendor docs: Spinal Cord Toolbox documentation

Other packages

ANTs, 3D Slicer, and ITK may appear in the codebase or as Coming soon entries. When a package is not enabled in the portal sidebar, treat it as unavailable for interactive runs until it is listed and Ready on your host.
