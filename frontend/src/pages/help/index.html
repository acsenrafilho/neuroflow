NeuroFlow user guide

NeuroFlow is a facilitation portal for neuroimaging CLIs on your machine. Each module is one page: upload data, set parameters, preview the command, and follow local execution logs—without building multi-tool pipelines. Full documentation: neuroflowpipelines.readthedocs.io.

info What NeuroFlow does not do

It does not install FreeSurfer, FSL, SCT, or other packages; does not auto-install WSL on Windows; does not chain stages into an automatic pipeline; and does not require Docker in this repository. Host tools stay on the OS where the API runs (Ubuntu when using WSL on Windows).
