Tips

Short habits that keep jobs predictable. Longer list: Tips on Read the Docs.

  • Prefer the form and CLI preview. Do not paste a full shell line into the portal.
  • After sourcing FreeSurfer, FSL, or SCT, rescan (POST /api/v1/host/rescan) or restart the API.
  • Run one job per stage (TOPUP before EDDY, FDT before BEDPOSTX, cord segmentation before CSA).
  • For CSA by vertebral level, use a vertfile plus -vert and -perlevel — see T1 cervical morphometry.
  • Use a stable workspace name and coded IDs such as sub-001.
  • Expect FreeSurfer -all to run for hours; watch Active processes on Home.
  • If queued, check RAM/CPU limits and NEUROFLOW_MAX_QUEUED_JOBS.
  • If the UI looks broken, run make frontend-build and serve frontend/dist/.
  • Stop a desktop instance with ./scripts/neuroflow-stop.sh.
