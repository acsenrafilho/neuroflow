T1 cervical morphometry

Checklist for CSA and shape metrics at C1–C3 from a T1-weighted brain (head) scan using Spinal Cord Toolbox. Each stage is a separate NeuroFlow job. Longer copy: T1 morphometry on Read the Docs.

Confirm C1–C3 are in the field of view before processing. Gray-matter (T2*) and DTI are not part of this workflow. The portal does not chain jobs automatically.

Job order

  1. Visual QC: exclude the scan if the cord is cropped at C1–C3.
  2. sct_deepseg — task spinalcord. Pass if the mask is continuous without CSF leak at the foramen magnum.
  3. sct_qc — process sct_deepseg_sc (T1 + segmentation). Open index.html on disk; NeuroFlow does not embed an image viewer.
  4. sct_label_vertebrae — contrast t1 (the form default is t2). Pass if C1, C2, and C3 match anatomy.
  5. sct_qc — process sct_label_vertebrae with the labeled segmentation. Pass if labels are not shifted.
  6. sct_process_segmentation — upload the segmentation and vertfile; -vert 1:3 and -perlevel 1. Pass if the CSV has rows for levels 1–3.

CSV columns

Keep vertebral level, MEAN(area) (CSA), MEAN(diameter_AP), MEAN(diameter_RL), and MEAN(eccentricity). Do not use a global CSA (no -vert) as the study output.

If labeling fails

Automatic labels on brain T1 often fail at the cranio-cervical junction. Correct them on the host (FSLeyes or sct_label_utils) and re-run CSA. Those tools are not portal modules.

Process one subject at a time until QC is stable, then batch multiple NIfTIs on the same module if needed. PAM50 registration is not required for native-space C1–C3 CSA.
